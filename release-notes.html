🚀 Version 2.0 Released

Release notes

Track updates, new features, and refinements across the Awesome Prompt Library. This changelog details enhancements made to organize prompts, improve navigation, and expand support for everyday writing.

Version 2.0 Current release
September 2026

Version 2.0 is a major leap forward for the Awesome Prompt Library. This release modernizes all 73 prompts with frontier prompting structures and file upload guidance, expands the library with 22 general writing prompts, introduces domain-based navigation with high-contrast filtering, and adds an interactive variable customizer with direct AI tool launching.

Frontier prompt architecture

  • Structured XML delimiters. Prompts now feature explicit sections for input sources, contextual parameters, step-by-step instructions, and output formats.
  • Document attachment guidance. Prompts specify relevant file formats (such as PRDs, OpenAPI schemas, transcripts, and resumes) so you can attach files directly to modern AI models.
  • Direct active imperatives. Removed polite filler phrases and pleasantries to focus attention weight on core requirements and prevent sycophantic model outputs.

Card uniformity and pro tips

  • Uniform pro tips across all 73 cards. Every prompt card now displays an actionable, field-tested tip to help you achieve consistent card heights across the grid.
  • Strict style guide alignment. Prompts and UI copy strictly follow the Microsoft Writing Style Guide, using active voice, sentence case, and zero em-dashes.

Navigation and discovery

  • Filter prompts by primary domain. Switch between All Prompts, General Writing, Technical Writing, and Saved prompts using the top navigation bar.
  • Browse contextual subcategories. Select secondary filter pills to view specific topics, such as Blogs & Articles, Social Media, and Miscellaneous.
  • Identify active filters easily. View active subcategories highlighted with domain-specific accent colors and high-contrast white text in both light and dark modes.

General writing prompt additions (22 prompts)

  • Draft social media posts. Create engaging content for LinkedIn posts, Instagram captions, X/Twitter threads, and YouTube video openers.
  • Compose clear workplace communications. Write professional emails for declining requests politely, following up gently, and handling sensitive conversations.
  • Build career assets. Format achievement-focused resume bullet points using the Google XYZ formula, tailored cover letters, executive bios, and interview thank-you notes.
  • Optimize articles and newsletters. Generate high-converting headlines, audit blog drafts against the Microsoft Style Guide, and craft memorable newsletter introductions.
  • Clarify complex thoughts. Explain technical concepts using simple analogies, challenge assumptions with counterarguments, and translate industry jargon into plain language.

Interface and prompt card refinements

  • View cleaner prompt cards. Focus on prompt titles, use cases, and prompt text without redundant category badges inside individual cards.
  • Customize variable placeholders. Fill in bracketed parameters using an interactive form preview before copying your prompt.
  • Open prompts directly in AI tools. Launch prompts into ChatGPT, Claude, Google Gemini, Perplexity, or Microsoft Copilot with official brand logos.
  • Save favorites locally. Bookmark prompts using the star icon to keep frequently used prompts accessible across browser sessions.

Data architecture and export

  • Load prompts dynamically. Access the entire prompt catalog via structured JSON (data/prompts.json) for faster rendering and easier maintenance.
  • Export filtered prompts. Download current views as formatted Markdown (.md) or JSON (.json) files for documentation repositories and wikis.
Version 1.0 Initial release
Initial release

Version 1.0 established the initial prompt library designed specifically for technical writers, documentarians, and software engineers.

Technical writing prompt collection (51 prompts)

  • Document API endpoints. Generate accurate reference documentation for GET, POST, and PUT operations with request and response examples.
  • Create CLI guides. Formulate command-line parameter summaries, installation steps, and syntax guidelines.
  • Structure product documentation. Write conceptual overviews, architecture summaries, and getting-started guides.
  • Develop troubleshooting resources. Produce error code catalogs, diagnosis workflows, and resolution guides.
  • Plan documentation strategies. Create content audit frameworks, information architecture outlines, and release notes templates.

Core platform features

  • Search prompts in real time. Query prompts by keyword, topic, or target task using the instant search bar.
  • Copy prompts with one click. Transfer clean prompt text to your clipboard instantly with toast notification feedback.
  • Toggle visual themes. Switch between light mode and dark mode with persistent user preferences.
  • Track community engagement. Display visitor metrics via a live page visit counter.
